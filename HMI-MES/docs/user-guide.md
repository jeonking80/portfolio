# 사용 안내

공개 화면: <https://hmi-mes.vercel.app>

## 먼저 알아 둘 것

- **설비 쪽은 항상 켜져 있지 않습니다.**
  - 꺼져 있으면 값이 "최신 아님"으로 나오고 운전 버튼은 잠깁니다.
  - 고장이 아니라 정상 표시입니다.
- **로그인 없이 둘러보기(조회 전용)**로 모든 화면을 볼 수 있습니다. 운전·등록은 할 수 없습니다.
- **판정은 PLC가 합니다.** 화면은 요청만 보내고, PLC의 결과를 확인해 보여 줍니다.
- **"불명"은 근거가 없다는 뜻입니다.** 통신이 끊겼거나 기록이 없는 시간이며, 정상이나 정지로 바꿔 채우지 않습니다.

## 생산 한 번 해 보기

1. **공정 설정 · 품목** — 품목을 고르고 온도·속도·공압을 입력해 공정 설정을 등록합니다. 배포한 설정은 고치지 않고 새 버전을 만듭니다.
2. **작업지시** — 공정 설정과 목표 양품 수량을 정하고 **등록하고 바로 배포**를 누릅니다.
3. **운전 제어 ① 설비 전원** — 전원을 켭니다. 60분 뒤 자동으로 꺼집니다.
4. **② 작업 준비** — 배포된 작업지시를 골라 불러옵니다. 예열 후 자동 시작, 목표 도달 시 자동 종료를 선택할 수 있습니다.
5. **③ 예열** — 실링 온도가 설정값에 도달하면 PLC가 예열 완료를 판정합니다.
6. **④ 생산** — 양품/목표 수량을 봅니다.
   - 일시정지·재개를 할 수 있습니다.
   - 운전 중에 라인 속도(±20%), 실링 온도(±10 ℃), 실링 공압(±0.5 bar)을 바꿀 수 있습니다.
   - 허용 범위를 벗어난 값은 서버가 먼저 막고, 최종 판정은 PLC가 합니다.
7. **⑤ 종료 · 정산**
   - 작업 종료를 누르면 신규 투입을 멈추고 라인에 남은 제품을 정리합니다.
   - 설비 최종 수량과 대조가 끝나면 정산 결과가 나오고 작업 준비 단계로 돌아갑니다.
8. **다음 작업** — 같은 작업지시를 다시 불러오면 새 회차로 실행되고, 실적은 회차별로 남습니다.

## 요청 상태 읽는 법

| 표시 | 뜻 | 할 일 |
| --- | --- | --- |
| 요청 저장 → PLC 접수 → 실행 완료 | 단계별 진행 | 기다립니다 |
| 거절 | PLC가 조건 미충족으로 거절 | 화면의 사유를 확인합니다 |
| 결과 불명 | 응답을 확인하지 못함 | **지난 요청 결과 찾기**에서 원래 ID로 조회하고 설비 값을 확인합니다. 같은 요청을 새로 다시 보내지 않습니다 |
